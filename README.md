# ユウコクラブ（夕食レシピ提案アプリ）

冷蔵庫の食材・人数・好みから、夕飯の献立（主菜・副菜・汁物）とレシピを考えるスマホ向けアプリです。
**有料のAPIは使っていません。** 献立とレシピを考える部分はAIを使わず、スマホの中だけで動きます。

---

## できること

| 機能 | 内容 |
|---|---|
| 食材から提案 | 冷蔵庫の食材を入れると、手持ちを一番多く使える献立を3案出します。足りない食材は「買い足すもの」に出します。☆を付けた食材は優先して使います |
| 冷蔵庫の残り | 「豚こま 300g」「キャベツ 半分」のように量も書けます（書かないと1パック分とみなします）。「作った！」を押すと使った分を自動で引き、なくなった食材は一覧から消えます（自分で登録したレシピは材料の重さが分からないので引きません。量を押して直してください）。「元に戻す」もあります。手持ちが足りない料理には注意が出ます |
| 新しいレシピ | 定番レシピ22品のほかに、「食材×調理法×味付け」を組み合わせてその日のレシピを作ります（相性の悪い組み合わせは作りません） |
| おまかせ献立 | 食材を指定しなくても3案出します。主菜＋副菜＋汁物／主菜＋副菜／主菜＋汁物／主菜だけ を選べます |
| 人数と分量 | 大人・子ども・小さい子の人数で分量を計算します。調味料は「食材の重さに対する塩分」で計算するので、量を倍にしても濃くなりすぎません。煮汁の水や香辛料は人数どおりには増やしません |
| 好み・苦手 | 苦手な食材、子どもが食べない食材、味の好み（酸味・お酢・ポン酢・トマト・甘辛・子どもの辛味）を保存して毎回反映します |
| レシピ詳細 | 料理名・完成イメージの絵・材料と分量・調味料・下ごしらえ・切り方と大きさ・手順（火加減と時間つき）・失敗しやすいポイント・コツ・子どもの取り分け・代用食材 |
| 調理モード | 1手順ずつ大きな字で表示。火加減（炎の見え方とIHの目安）・時間・見た目の目安をいつも表示。タイマーつき。画面が暗くならないようにします（対応しているブラウザのみ） |
| 困った？ | 「水分が出てきた」「焦げそう」「火が通ったか分からない」などに、いまの手順に合わせて答えます（AIではなく、よくある困りごとへの答え） |
| 記録・お気に入り | 作った料理と評価（おいしかった／普通／好みではなかった）を保存し、次の提案に生かします。7日以内に作った料理と似たものは出にくくなります |
| アプリ以外で作った料理 | ホームの「アプリ以外で作った日は？」に料理名を入れると、味付けと主役を自動で判断して記録します（外食・お惣菜もOK。違えば「直す」で選び直せます）。3日以内は同じ味付けが出にくくなります |
| わが家のレシピ | 自分のレシピを登録できます。ChatGPTなどの答えを貼り付けて読み込むこともできます。献立の候補にも入ります |
| AIに頼みたいとき | 条件をまとめた文を作って、無料版のChatGPTに貼れます。Geminiの無料キーを入れると、調理中の質問にアプリの中で答えが返ってきます（使わなくてもOK） |

### 正直に書いておくこと

- **「組み合わせ提案」は、実際に作って確かめたレシピではありません。** 調味料は一般的な配合と塩分の目安（炒め物は食材の重さの約0.9%、煮物は約0.75%、汁物は汁の約0.7〜0.85%）から計算しています。最後に味見をして調整してください
- 「定番の作り方」は、家庭でよく作られている一般的な配合です
- 完成イメージは写真ではなく、食材の色と形から描いたイメージ図です
- データ（設定・記録・登録したレシピ）は、そのスマホのブラウザの中だけに保存されます。機種変更の前に「せってい」→「書き出す」で保存してください

## ファイルの中身

```
index.html            画面のもと
style.css             見た目
js/engine.js          献立とレシピを組み立てる仕組み（塩分の計算・分量・手順の文章）
js/app.js             画面の動き（保存・調理モード・タイマー・困った？・Gemini）
js/plate.js           完成イメージの絵を描く部品
data/ingredients.json 食材の辞書（切り方・加熱時間・コツ・代用）
data/seasonings.json  調味料の辞書（小さじ1の重さ・塩分）
data/sauces.json      味付けの辞書（どの食材と組み合わせてよいか・配合）
data/classics.json    定番レシピ22品
data/help.json        調理中の「困った？」の答え
sw.js                 一度開いたら電波がなくても使えるようにする仕組み
manifest.webmanifest  ホーム画面に置いたときの名前とアイコン
icons/                アイコン
robots.txt            検索サイトに載せないための設定
```

## 動作確認の方法（パソコンで）

1. このフォルダで「ターミナル」を開き、次を入力して Enter
   - Mac：Finderでこのフォルダを右クリック →「フォルダに新規ターミナル」（出ないときは、ターミナルを開いて `cd ` と入力し、フォルダをドラッグして Enter）
   - Windows：フォルダを開いて、上のアドレス欄に `cmd` と入力して Enter。Pythonが入っていなければ https://www.python.org から入れて、下の `python3` を `py` に変えて入力します
   ```
   python3 -m http.server 8000
   ```
2. ブラウザで `http://localhost:8000` を開く
   - ※ index.html をダブルクリックで直接開くと、データが読めずに動きません。必ず上の方法で開きます
3. 次を順に試します

| 試すこと | うまくいっていれば |
|---|---|
| 「冷蔵庫にあるもの」に `豚こま キャベツ にんじん 卵 豆腐 ねぎ` と入れて Enter | 6つの食材が並び、それぞれに量（1パック分）が出る |
| 「献立を考える」を押す | 3案出て、「使う食材」「残る食材」「買い足すもの」が出る |
| 料理名を押す → 人数の＋を押す | 材料と調味料の量が変わる |
| 「調理モード」→「次へ」 | 手順ごとに火加減・時間・見た目の目安が出る |
| 「タイマー開始」 | 画面の上にタイマーが出て、時間になると音が鳴る |
| 「困った？」→「水分がけっこう出てる」 | 調理法に合った答えが出る |
| 「作った！」→「おいしかった」 | 「きろく」に入り、料理に「わが家で好評」が付く。冷蔵庫の量が減り、使い切った食材が一覧から消える |
| 「せってい」で苦手な食材を足す | その食材を使う料理が出なくなる |
| ページを再読み込みする | 設定・記録・最後の献立が残っている |

## 公開の手順（GitHub Pages・無料）

スマホで開けるように、インターネット上に置きます。GitHub Pages は無料で、回数の制限もほぼありません。

1. https://github.com でアカウントを作る（無料）
2. 右上の「＋」→「New repository」
   - Repository name：好きな名前（例：`yuuhan-app`）
   - 「Public」を選ぶ（無料で公開するには Public が必要です。中身はレシピのデータだけで、個人の情報は入っていません）
   - 「Create repository」を押す
3. 「uploading an existing file」を押し、このフォルダの中身（index.html、style.css、js、data、icons などすべて）をドラッグして入れる → 「Commit changes」
4. 「Settings」→ 左の「Pages」→「Source」が「Deploy from a branch」になっているのを確かめ、「Branch」を `main`、フォルダを `/ (root)` にして「Save」
5. 1〜2分待つと、`https://（アカウント名）.github.io/（リポジトリ名）/` で開けるようになります
6. iPhoneのSafariでそのURLを開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます

### 直したファイルを公開し直すとき

- `sw.js` の `var VERSION = 'yuuhan-v5';` の数字を `yuuhan-v6` のように1つ上げてから、リポジトリの画面の「Add file」→「Upload files」で、直したファイルを上書きアップロードします（数字を上げないと、スマホに古い画面が残ることがあります）

### Netlify でもOK

https://app.netlify.com/drop にこのフォルダをドラッグするだけでも公開できます。先にNetlifyのアカウントを作ってログインしてから上げてください（ログインしないで上げると、一時的な公開で終わることがあります）。無料枠には月の回数制限があります。

## レシピを足したいとき

- いちばん簡単なのは、アプリの「レシピ」→「レシピを登録」です（そのスマホにだけ保存）
- みんなのスマホに入れたいときは `data/classics.json` に足します。書き方は、すでにある料理を1つコピーして書きかえるのが安全です
  - 分量は「大人2人分」で書きます。調味料は `"tsp"`（小さじの数。大さじ1＝3、水100ml＝20）で書きます
  - 手順の中の `{shoyu}` のような書き方は、人数に合わせた分量に置きかわります
- 食材を足したいときは `data/ingredients.json`、組み合わせてよい味付けを変えたいときは `data/sauces.json` を直します

## Gemini のキー（使わなくてもOK）

調理中の「困った？」で自由な質問に答えが返ってくるようにする、任意の機能です。

1. https://aistudio.google.com/apikey を開き、自分のGoogleアカウントでログイン
2. 「APIキーを作成」を押して、表示されたキーをコピー
3. アプリの「せってい」→「調理中の質問にGeminiを使う」に貼って「保存」→「つながるか試す」

注意（2026年11月にGoogleの公式ページで確認）

- 無料で使えます。お支払い方法の登録はしないでください
- 無料の使い方では、送った質問と答えをGoogleがサービス改善に使い、人が読むこともあります。名前や住所などは書かないでください（アプリが送るのは料理名・材料・手順・質問だけです）
- 1日の回数に上限があります（上限はモデルごとに決まっていて、AI Studio の画面で確認できます）
- Googleの規約で、キーを作って使えるのは18歳以上です
- 使うモデルは `gemini-3.5-flash-lite` から順に試します。Googleがモデルの名前を変えたときは `js/app.js` の `GEMINI_MODELS` を直します
